# Тесты Part 4: Хранилище-словарь, UUID-идентификаторы, индекс имён и корзина-словарь

## Описание тестов

### Базовые функции

- **test_normalize_product_name** — проверяет нормализацию названий товаров (удаление лишних пробелов, приведение к нижнему регистру)
- **test_constants** — проверяет правильность глобальных констант (`PROMPT`, `TABLE_HEADERS`)
- **test_get_storage_str_representation** — проверяет формирование текстовой таблицы хранилища

### Генерация идентификаторов

- **test_generate_product_id** — проверяет генерацию UUID идентификаторов (тип, длина, версия UUID4, уникальность)

### CRUD операции

- **test_create_product** — проверяет создание товара (нормализация имени, округление цены, проверка на дублирование имён, отвержение пустых имён)
- **test_read_product** — проверяет чтение товара из хранилища по идентификатору, обработку несуществующих товаров
- **test_update_product** — проверяет частичное обновление товара (обновление только нужных полей, проверка на конфликт имён, отвержение пустых имён)
- **test_delete_product** — проверяет удаление товара из хранилища и из индекса имён

### Операции с корзиной

- **test_add_to_cart** — проверяет добавление товара в корзину (перемещение со склада, уменьшение количества, обработка недостатка товара)
- **test_remove_from_cart** — проверяет удаление товара из корзины (перемещение обратно на склад, увеличение количества, удаление при нулевом количестве)

### Консоль администратора

- **test_show_help** — проверяет вывод справки по командам
- **test_print_result** — проверяет форматированный вывод результатов операций
- **test_run_command_help_exit** — проверяет работу команд `help` и `exit`
- **test_run_command_create** — проверяет работу команды `create` и генерацию новых товаров
- **test_run_command_show** — проверяет вывод таблицы всех товаров
- **test_run_command_read** — проверяет чтение одного товара по id
- **test_run_command_update** — проверяет обновление товара через консоль
- **test_run_command_delete** — проверяет удаление товара через консоль
- **test_run_command_not_a_command** — проверяет обработку неизвестных команд и неверного числа аргументов
- **test_run_command_invalid_arguments** — проверяет обработку невалидных значений цены и количества

### Интеграционные тесты

- **test_main_session** — проверяет полный сценарий работы консоли (создание товаров, вывод таблицы, чтение товара)
- **test_main_catches_invalid_arguments** — проверяет обработку ошибок парсинга в главном цикле

## Структура тестов

Все тесты расположены в `tests/part4/test_general.py` и покрывают следующие модули:
- `src/part4/storage.py` — типы данных и константы
- `src/part4/crud.py` — операции создания, чтения, обновления, удаления
- `src/part4/cart.py` — операции с корзиной покупателя
- `src/part4/utils.py` — утилиты нормализации и представления
- `src/part4/run_admin.py` — интерактивная консоль администратора

## Инварианты, проверяемые тестами

1. **Инвариант индекса имён**: `product_names` всегда равно множеству нормализованных имён в хранилище
2. **Нормализация**: все имена нормализованы, все цены округлены до `PRICE_PRECISION`
3. **Уникальность**: названия товаров уникальны в нормализованной форме
4. **Сохранение количества**: сумма количества на складе и в корзине для каждого товара остаётся неизменной
5. **UUID идентификаторы**: идентификаторы являются валидными UUID версии 4 и уникальны

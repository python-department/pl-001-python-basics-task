# Сдача домашнего задания

Чтобы работа была принята на проверку, выполните шаги ниже по порядку.

## 1. Выполните задание

Выполните все пункты задания и оформите решение в соответствующих файлах. Перед отправкой [запустите локальные проверки](local_checks.md), чтобы заранее найти ошибки в оформлении кода.

## 2. Залейте решение в свой форк

Решение должно лежать в вашем форке репозитория на GitHub. Если форка ещё нет, создайте его кнопкой **Fork** на странице исходного репозитория, затем закоммитьте изменения и отправьте их в форк:

```bash
git add .
git commit -m "Solve task 1"
git push
```

## 3. Откройте Pull Request

Откройте Pull Request из своего форка в [исходный репозиторий](https://github.com/python-department/pl-001-python-basics-task).

Оформите его так, чтобы название соответствовало шаблону: `номер задания. ФИО студента. номер группы`. Пример: `1. Иванов Иван Иванович. 123`.

## 4. Дождитесь результатов CI

Pull Request будет проверен только в том случае, если он оформлен корректно (название и лейбл соответствуют требованиям), а все проверки CI пройдены успешно. Если какая-то проверка упала, исправьте замечания, запушьте изменения в тот же форк и дождитесь нового запуска CI.

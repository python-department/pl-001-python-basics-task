# Запуск локальных проверок

Перед тем как открыть Pull Request, прогоните у себя те же проверки, что запускаются в CI на GitHub. Так вы найдёте ошибки заранее, не дожидаясь результата CI.

## Что проверяется

Скрипты устанавливают зависимости, затем проверяют код в папке `src`: линтером, форматированием и статическим анализатором типов. Если какая-то проверка не пройдена, скрипт останавливается с ошибкой.

## Установка uv

[uv](https://docs.astral.sh/uv/) — менеджер пакетов и окружений для Python. Проверки запускаются через него, поэтому вам потребуется его установить.

### macOS

Через официальный установщик:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

Или через Homebrew:

```bash
brew install uv
```

### Windows

Через PowerShell:

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

Или через winget:

```powershell
winget install --id=astral-sh.uv -e
```

### Проверка установки

Закройте и снова откройте терминал (иначе он не увидит обновлённый `PATH`), затем выполните:

```bash
uv --version
```

Если команда напечатала версию, всё готово. Другие способы установки описаны в [документации uv](https://docs.astral.sh/uv/getting-started/installation/).

## Запуск проверок

Скрипты лежат в корне репозитория. Их можно запускать из любой папки, они сами переходят в корень проекта. Если `uv` не установлен, скрипт напечатает сообщение об этом и завершится.

### macOS / Linux

```bash
./run_local_checks
```

Если появилась ошибка `Permission denied`, сделайте скрипт исполняемым и запустите снова:

```bash
chmod +x run_local_checks
./run_local_checks
```

### Windows

В PowerShell или в командной строке (cmd):

```powershell
.\run_local_checks.bat
```

Если у вас установлен Git Bash, можно запустить и bash-версию:

```bash
./run_local_checks
```

## Как читать результат

Скрипт печатает заголовок каждого шага (`==> Ruff lint` и так далее). При успехе в конце выводится `All checks passed.`

Если какой-то шаг упал, исправьте замечания из его вывода и запустите скрипт снова. Форматирование можно исправить автоматически:

```bash
uv run ruff format src
```
